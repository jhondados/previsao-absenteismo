# 👥 Previsão de Absenteísmo

> Previsão de absenteísmo com ML. Antecipa faltas e afastamentos por área, apoiando o planejamento de escala e a saúde ocupacional.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/previsao-absenteismo/

[![Vertical](https://img.shields.io/badge/Vertical-RH-blue)]() [![IA](https://img.shields.io/badge/IA-ML-green)]() [![Demo](https://img.shields.io/badge/Demo-Interativa-orange)]()

## 📊 Resultados-chave (KPIs)
**88%** Acurácia · **-19%** Absent. · **semanal** Antecip. · **otimizada** Escala

## 🧠 Tecnologias de IA
ML · Time Series · Classification

## ✨ O que faz
- Previsão de faltas por área
- Identificação de padrões
- Planejamento de escala
- Saúde ocupacional

## 🗄️ Fonte de dados real
[Ponto + afastamentos](https://www.gov.br/trabalho)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com Ponto + afastamentos
2. **Processamento com IA** — ML · Time Series · Classification
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
